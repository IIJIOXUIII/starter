# ADR-001: Монорепозиторий — pnpm workspaces + Turborepo + go.work

- Статус: принято (M0)
- Дата: 2026-11-22

## Контекст

Платформа объединяет TypeScript (Nuxt, микрофронты, пакеты) и Go (микросервисы).
Контракты (OpenAPI/proto) связывают обе стороны: изменение контракта и его
реализации должны попадать в один PR.

## Решение

- Единый git-репозиторий.
- TS-часть: pnpm workspaces + Turborepo (кеш задач, топологический порядок
  `generate → build → test`).
- Go-часть: `go.work` — workspace из трёх модулей (`pkg`, `services/auth`,
  `services/users`); новые сервисы добавляются как отдельные модули.
- Связки между экосистемами — через justfile/CI (Go не участвует в turbo-пайплайне).

## Альтернативы

- **Nx** — мощнее для полиглот-репо, но тяжелее и избыточен на старте.
- **Полиглот-мультирепо** — atomic-изменения контрактов невозможны, дрейф версий.

## Последствия

- Атомарность «контракт + код» — главный выигрыш.
- Turborepo не знает про Go: оркестрация Go-задач — CI/justfile.
- Монорепо вырастет — ограничиваем размер git-истории (без бинарников, LFS при необходимости).
